One line roasting the phone I use every day: its face unlock recognises me at 3 a.m. but not in sunlight with sunglasses on.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.txt`, the
path the grader reads. The line is 119 characters, one line, no
trailing newline.
